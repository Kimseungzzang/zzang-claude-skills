Summarize today's conversation and save it to Obsidian vault.

## Step 1 — Daily Note

Create or append to the file `~/obsidian-vault/Daily/YYYY-MM-DD.md` (use today's date).

Organize the conversation by topic. For each topic, write:

```
## [Topic Title]

**Q:** [User's question]

**A:** [Your answer, summarized concisely]
```

## Step 2 — Project Note

Identify the project name from the current working directory or conversation context.

Create or update the file `~/obsidian-vault/Projects/[ProjectName].md`.

Include the following sections:

### Commits & Changes
List commits or diffs discussed in this session. For each change, describe what was implemented.

### Implementation Summary
Use a Mermaid diagram to visualize the implemented features, data flow, or component relationships discussed in this session. Choose the most appropriate diagram type (flowchart, sequenceDiagram, classDiagram, etc.).

```mermaid
[generate appropriate diagram here]
```

### Session Log
Brief bullet-point summary of what was discussed and decided in this session.
